# Zerem Energy

Адаптивный прототип главной страницы: Next.js App Router, React, TypeScript, Tailwind CSS 4.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, показанный сервером (обычно http://127.0.0.1:3000).

## Проверка и production

```sh
npm run typecheck
npm run build
npm start
```

## Vercel

Проект подключён к GitHub и автоматически публикуется в Vercel из ветки `main`. Root Directory — `zerem-energy`, команда сборки — `npm run build`, output directory — стандартное значение Next.js. Переменные окружения для текущей версии не требуются.

## Структура

- `app/page.tsx` — главная страница и данные секций.
- `app/globals.css` — Tailwind, визуальные токены, desktop/mobile стили.
- `app/layout.tsx` — язык и SEO metadata.
- `components/Header.tsx` — логотип и адаптивная навигация.
- `public/images/` — локальная оригинальная иллюстрация.
- `public/project-brief.txt` — скачиваемый бриф.

Разделы Solutions / Industries / Equipment / About доступны через якорную навигацию. При расширении сайта их можно вынести в отдельные маршруты App Router.

## Что необходимо перед публикацией

- Утвердить юридическое название, контакты и фактические характеристики компании.
- Заменить демонстрационные email, телефон и адрес на реальные данные.
- Подключить подготовленную форму заявки к подтверждённому адресу или CRM. Сейчас данные формы не отправляются и не сохраняются.
- При необходимости предоставить исходное изображение утверждённого макета для точной сверки: в доступной истории чата были только описание и тексты, без изображения макета.
