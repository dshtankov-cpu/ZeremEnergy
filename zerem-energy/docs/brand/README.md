# Zerem Energy logo assets

Approved navy and orange concept PNGs are in public/brand/: zerem-white.png, zerem-dark.png, and zerem-symbol.png. The header uses the white version; the footer uses the dark version; browser metadata uses the standalone symbol.

The full logo PNGs include presentation margins. The brand-logo CSS frame hides those margins without changing the source files. Update the frame if the source composition changes.

Palette targets: navy #142D55, orange #F47721. These are generated raster concepts, not vector masters.

The transparent attempt in drafts/ contains an unwanted halo and is not used by the website.
